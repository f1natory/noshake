# No Shake

![Fabric](https://img.shields.io/badge/Loader-Fabric-DBD0B4?style=for-the-badge)
![Environment](https://img.shields.io/badge/Environment-Client-4C8BF5?style=for-the-badge)
![License](https://img.shields.io/badge/License-MIT-yellow?style=for-the-badge)

**No Shake** removes the delayed first-person hand rotation that occurs when moving your camera.

Your hand follows the camera instantly, making movement feel cleaner, sharper, and more responsive.

## ✨ Features

- Removes horizontal hand sway
- Removes vertical hand sway
- Keeps item use and attack animations intact
- Works entirely on the client
- No Fabric API required
- Lightweight and compatible with multiplayer servers

## 📦 Installation

1. Install [Fabric Loader](https://fabricmc.net/use/installer/).
2. Download **No Shake**.
3. Place the `.jar` file into your Minecraft `mods` folder.
4. Launch the game.
